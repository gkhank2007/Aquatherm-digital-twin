# AquaTherm Digital Twin

An IHL working model that simulates water-level dynamics, temperature
changes, and pump control in a water tank.

## Features

-   Water-level monitoring and simulation
-   Water-temperature simulation
-   Automatic and manual pump-control modes
-   Interactive dashboard and graphs
-   Adjustable simulation parameters

## How It Works

The model represents a pumped water tank. Water level changes according
to the balance between inflow and outflow. Water temperature is modelled
using incoming-water temperature and heat exchange with the
surroundings.

## Applications

-   Water management
-   Industrial tank monitoring
-   Agricultural irrigation
-   Engineering education

## Future Scope

-   IoT sensor integration
-   Real-time monitoring
-   AI-based prediction
-   Energy-efficient pump control
